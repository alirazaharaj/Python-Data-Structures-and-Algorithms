# Python Data Structures and Algorithms (DSA)

Welcome to my DSA journey! This repository contains my clean, from-scratch implementations of fundamental computer science data structures using Python. Moving forward from basic programming, this project serves as a practical blueprint for mastering algorithmic problem-solving.

---

## 📂 Repository Structure

The codebase is organized into logical categories separating linear and non-linear data layouts:

```text
Python-Data-Structures-and-Algorithms/
│
├── Linear_Data_Structures/
│   ├── Arrays.py                   # Basic operations, tracking data, dynamic setups
│   ├── Stack.py                    # Last-In-First-Out (LIFO) stack operations
│   ├── Que.py                      # First-In-First-Out (FIFO) queues & double-sided deques
│   ├── linklist.py                 # Singly Linked List with index manipulation
│   └── linklist2.py                # Doubly Linked List with forward/backward traversal
│
└── Non_Linear_Data_Structures/
    ├── Hashmap.py                  # Custom Hash Map with chaining collision handling
    └── Tree.py                     # Hierarchical structural tree structures with recursive printing
